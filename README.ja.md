# ゲーム生成プロンプト図鑑 game-prompts

> 100 組の「AI ゲーム生成プロンプト」を収めた静的図鑑。各組は固定の 9 段階
> （コンセプトアート → プロトタイプレベル → 操作感 → 経験値 → 識別装備 → ルール一 → ルール二 → 七区拡張 → 収集システム）で構成され、
> 全文・段階ごとのコピー、プレーンテキストのダウンロード、
> 自分のゲーム文書や小説プロジェクト JSON からの LLM による新規生成ができます。

## 試してみる

- `index.html` をブラウザで開くだけで閲覧できます（純フロントエンドモード、インストール不要）。
- GitHub Pages にデプロイすれば、リンクを共有するだけで誰でも使えます（同じく純フロントエンドモード）。

## 機能一覧

- **検索**：スペース区切りの複数キーワード（AND）で全文検索、結果をハイライト。`/` または `Ctrl+K` で検索にフォーカス。
- **絞り込み／並び替え／表示**：カテゴリ chips、お気に入り chip、並び替えドロップダウン（表ヘッダーのクリックも可）、テーブル／カード切り替え（モバイルは自動でカード）。
- **ドロワー**：段階ビュー（各段階を個別コピー、「貼り付け済み」チェックで進捗管理）／原文ビュー；`←` `→` で前後移動、`c` で全文コピー、`f` でお気に入り。
- **共有 URL**：`#cat=分類&q=キーワード&p=slug` で同じ画面を再現・共有できます。
- **テーマ**：ダーク／ライト、既定で OS に追従、右上の 🌙／☀️ で切り替え。
- **UI 言語**：繁体字中国語／English／簡体字中国語／日本語／韓国語、右上で切り替え、ブラウザ言語を自動検出してローカルに記憶。翻訳されるのは UI とカテゴリ表示名のみで、100 組の本文・slug・カテゴリキーは不変のため、言語を変えても `#cat=` リンクは壊れません。
- **文書からの生成**：設計文書を貼り付け（または JSON をアップロード、例：`docs/example-novel.json`）、モデル選択 → 9 段階を生成 → **プレビューして編集可能** → 図鑑に保存。フォームは自動で下書き保存、生成中は中止可能、4 分無応答でタイムアウト。
- **モデル／Key 設定**：複数プロバイダー対応（OpenRouter、OpenAI、Anthropic、Gemini、Meta、カスタム OpenAI 互換エンドポイント）。Key はブラウザの localStorage にのみ保存され、キー名は Omni Code と共用です。
- **データ管理**：カスタム項目の一覧／削除、カスタム項目 JSON のエクスポート・インポート、現在の絞り込み結果の Markdown エクスポート、図鑑全体の JSON エクスポート、進捗とお気に入りのクリア。

## 開き方

| 方法 | できること |
| --- | --- |
| `index.html` を直接開く（file://）または GitHub Pages | 閲覧・検索・お気に入り・コピー・ダウンロード。LLM 生成結果はブラウザに保存され `.txt` が自動ダウンロードされます |

## 小説 JSON → ゲームプロンプト

自分の小説の世界観をゲーム企画に変えたいですか？手順は 3 ステップです：

1. **小説を生成**：[omnipd.cloud/app](https://omnipd.cloud/app) に登録し、完全なストーリー小説を生成します（キャラクター・世界観・章構成まで自動で構築されます）。
2. **JSON をエクスポート**：omnipd で小説プロジェクトを JSON ファイルとしてエクスポートします（物語・キャラ設定・章などのテキストフィールドを含みます）。
3. **ゲームプロンプトに変換**：本図鑑に戻り「生成」→ 先ほどの JSON をアップロード（形式は `docs/example-novel.json` を参照）→ モデル選択 → 9 段階のゲーム制作プロンプトを生成 → プレビュー・編集 → 保存。

仕組み：アップロードされた JSON はまずテキスト抽出されます（テキストフィールドのみ、base64 画像は自動除外。`assets/app-gen.js` の `gpExtractJsonText` を参照）。
次に同ジャンルの参考例 3 組（うち 1 組は必ず同カテゴリ、`gpPickRefs`）を添えて LLM に送信し、
返却フィールドを `gpBuildPrompt` が 9 段階テンプレートで全文に組み立てるため、形式はプログラムで保証されます。

## 自分の文書から生成する

1. 「生成」を押し、ゲーム設計文書（玩法・キャラ・世界観……具体的ほど良好）を貼り付けるか、JSON を直接アップロードします。
2. モデルを選択します（初回は Key 設定で API Key を登録）。
3. 生成 → LLM の応答待ち → プレビュー画面でタイトル・カテゴリ・各フィールド・全文を編集します。
4. 保存：PHP バックエンドがあれば `prompts/<slug>.txt` に書き込み図鑑を再構築、純フロントエンドモードではブラウザ保存＋ `.txt` 自動ダウンロードになります。

## モデルと Key 設定

- OpenRouter、OpenAI、Anthropic、Gemini、Meta AI、およびカスタム OpenAI 互換エンドポイントに対応。
- Key は自分のブラウザの localStorage にのみ存在し、外部サーバーに送信されることはありません（キー名は Omni Code と共用のため一度の登録で OK）。
- フロントエンドはプロバイダーへの直結を優先し、CORS で遮断された場合は PHP バックエンドが自動で `api/relay.php` 中継に切り替えます（プロバイダードメインのホワイトリスト制、Key はディスクに残りません）。

## プロジェクト構成

```
index.html            成果物：_gen/template.html + データから生成。手編集禁止
assets/app-gen.js     LLM 生成・モデル／Key 設定・データ管理（ページ内 window.GP に依存）
assets/i18n.js        5 言語 UI 辞書（dict）＋カテゴリ表示名（cats）。言語追加＝ langs 項目＋同キー辞書の追加
prompts/*.txt         100 組の原文。ファイル名＝slug
docs/example-novel.json  小説 JSON サンプル（アップロードして生成フローを試せます）
api/ping.php          バックエンド検出
api/relay.php         AI 中継（プロバイダードメインのホワイトリスト制、Key は保存しない）
api/save_prompt.php   prompts/<slug>.txt + _gen/custom.json に書き込み、index.html を再構築
api/delete_prompt.php custom.json 内の項目のみ削除、index.html を再構築
_gen/template.html    ページテンプレート（デザインシステム＋主プログラム）
_gen/data_1..4.php    内蔵 100 組データ（各 18 フィールド）
_gen/lib_catalog.php  PHP 版：内蔵＋カスタムを統合してテンプレート適用
_gen/build_index.js   Node 版：lib_catalog.php と等価。PHP がない場合に使用
_gen/build_index.php  PHP CLI 再構築エントリ
_gen/custom.json      カスタム項目一覧（バックエンドモード用。.gitignore 済み）
_gen/gen.php          data_*.php から prompts/*.txt を再生成
```

## テンプレやデータ変更後の再構築

```bash
node _gen/build_index.js
```

PHP がある場合：

```bash
php _gen/build_index.php
```

両者は同一出力です（内蔵 100 組 + `_gen/custom.json`）。`index.html` が参照する `assets/*.js` には内容ハッシュによる cache-busting が付くため、JS 変更後も再構築してください。`data_*.php` の内容を変更した場合は、先に `php _gen/gen.php` で `prompts/*.txt` を再生成してから再構築します。

## GitHub Pages へのデプロイ

1. 本ディレクトリを GitHub リポジトリに push します。
2. リポジトリ Settings → Pages → Source で `Deploy from a branch` を選択、ブランチ `main`・フォルダ `/ (root)` を指定します。
3. 数分待てば `https://<ユーザー>.github.io/<リポジトリ>/` で図鑑が開きます。
4. 注意：GitHub Pages は静的ホスティングのため `api/*.php` は実行されません——上表の「純フロントエンドモード」と同等です。閲覧・検索・生成（LLM 直結）・ダウンロードは正常動作し、カスタム項目はブラウザ localStorage に保存されリポジトリには書き戻されません。`_gen/custom.json` は `.gitignore` 済みのため個人データの誤 push を防げます。
